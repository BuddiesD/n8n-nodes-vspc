# VSPC API - n8n Custom Node\n\nThis is a custom n8n node for interacting with the **Veeam Service Provider Console (VSPC)** API. It allows you to fetch data from various endpoints in the VSPC API, such as backup jobs, management agents, triggered alarms, and tenant products.\n\n## Features\n\n- **Fetch Backup Jobs**: Retrieve a list of all backup jobs from VSPC.\n- **Fetch Management Agents**: Retrieve a list of management agents from VSPC.\n- **Fetch VB365 Organization Jobs**: Retrieve a list of all organization jobs from VB365 servers.\n- **Fetch Company Information**: Retrieve detailed information about specific companies using their `companyUid`.\n- **Fetch Products of all Tenants**: Retrieve all products of tenants, including their versions and more.\n- **Fetch Active Alarms**: Retrieve a list of all currently active alarms from VSPC.\n\n## Installation\n\nTo install this custom node in your n8n instance:\n\n1. **Clone this repository**:\n   ```bash\n   git clone https://github.com/BuddiesD/n8n-nodes-vspc.git\n   ```\n\n2. **Navigate to the project directory**:\n   ```bash\n   cd n8n-nodes-vspc\n   ```\n\n3. **Build the node**:\n   ```bash\n   pnpm build\n   ```\n\n4. **Add it to your n8n instance**. Refer to the [n8n documentation](https://docs.n8n.io/integrations/creating-nodes/) for detailed instructions.\n\n## Usage\n\nOnce installed, you can use the VSPC API node in your workflows. The node supports the following endpoints:\n\n- **Backup Jobs**: Retrieve a list of all backup jobs.\n- **Management Agents**: Get a list of management agents managed by VSPC.\n- **VB365 Organization Jobs**: Fetch jobs related to VB365 organizations.\n- **Company Information**: Get details about specific companies by providing the `companyUid`.\n- **Tenant Products**: Fetch all products assigned to tenants, including version details.\n- **Active Alarms**: Retrieve all currently triggered alarms with filtering and sorting options.\n\n## Authentication\n\nThe node uses **API Token-based authentication**. To connect to the VSPC instance, provide the following:\n\n- **Base URL**: The URL of your VSPC server (e.g., `https://your-vspc-server:port`).\n- **API Token**: A valid token with the necessary permissions.\n\nEnsure that the token is active and your account has access to the required endpoints.\n\n## License\n\nThis project is licensed under the MIT License.
